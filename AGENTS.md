# androsaur-audio

Звук Androsaur: отдельное Android-приложение, которое постоянно слушает микрофон и
сообщает о wake-word «Привет, Петя». Контекст продукта — `androsaur-brief.md` в
пространстве Androsaur; устройство каркаса — docs/ARCHITECTURE.md.

- Kotlin/Compose на Android; логика без Android (уровень, журнал событий, wake-word
  контракт) — в KMP-модуле `shared` с тестами. Структура и стиль повторяют mobile-ledger.
- Только это приложение читает микрофон. Остальные модули получают события, а не звук.
- Итоговый движок wake-word НЕ выбран (решение владельца). Porcupine отпал: бесплатный тариф
  закрыт 30.06.2026. Сейчас сменные `vosk` и `mww:*` (microWakeWord); всё остальное зависит
  только от интерфейса `WakeWordEngine`. Модель для «Привет, Петя» ещё не обучена.
- Модуль `microwakeword` — копия из Home Assistant Android (Apache 2.0), см. его NOTICE;
  менять нативный код только осознанно. Модель Vosk в git не коммитить (скрипт в `scripts/`).
- Сервоприводы не здесь: кто ими управляет, не решено. Не добавлять связь с ESP32.
- Порт локального сервера 8089 (камера занимает 8088). Каждый запрос требует Bearer-код.
  Не печатать код в логи и отчёты.
- Запуск сервиса из фона на Android 14–15 — главный непроверенный риск. Не считать
  решённым без проверки на Redmi 12 / Android 15; эмулятор это не подтверждает.
- Протокол событий пока локальный (HTTP и MCP). Общую библиотеку `androsaur-protocol`
  не создавать и не подключать без решения владельца.
- Для сборки нужны NDK 29.0.14206865 и CMake 3.22.1 в SDK; CMake скачивает исходники tflite-micro из сети.
- Проверки: `./gradlew :androidApp:assembleDebug :shared:jvmTest :androidApp:lintDebug`
  (нужен `local.properties` с `sdk.dir`, он в .gitignore).
